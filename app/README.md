# Federation Studio 前端

React 19 + TypeScript 6 + Vite 8 的交互原型。

```bash
npm install
npm run dev:demo
```

打开 <http://127.0.0.1:8880/>。

提交前运行：

```bash
npm run check
```

当前前端包含 9 类联邦工作负载的分层配置和七步 Run 向导。页面中的上传、Agent、沙箱、联邦执行、评测和发布均为模拟能力，未连接真实后端。

项目介绍、架构、进度和扩展方式见根目录 [README](../README.md) 与 [开发说明](../docs/DEVELOPMENT.md)。
