# 当前进展

更新时间：2026-09-29
版本：0.4.0 前端原型（联邦 Agent）

## 一句话状态

项目已改为只做联邦 Agent。前端原型可以完整演示使用方式：

- 先选场景，再选算法和数据，然后发起联邦任务；
- 看每轮进度和"本地 vs 联邦"的结果；
- 把产出发布为应用，并试用或导出。

任务运行和结果都是示例数据；后端、FoT 引擎、模型网关和参与方本地客户端尚未实现。

## 已完成（前端）

### 场景、算法与数据

- 3 个场景：
  - 横向联邦 Agent：可用，算法是 FoT；
  - 纵向联邦 Agent、联邦迁移 Agent：规划中，只说明用途和所需数据。
- 算法注册表：FoT 声明了适用的任务类型、交换内容（文本 trace）、产出（洞见库）、4 个可调参数和每轮 6 步。
- 内置 8 个数学推理数据集（AIME24、AIME25、AMC、CCEE、CNMO、WLPMC、V202412Hard、V202505Hard，共 300 条样本），各由一个平台托管的示例参与方持有。另有一个等待连接的本地参与方示例。

### 页面

平台按通用情况设计：场景、算法、任务类型、算法参数、每轮步骤、交换内容和产出都来自注册表，FoT 只是目前登记的算法。导航和原 TrustFLAIR 平台一致：首页、联邦任务、应用、基础管理。

- **首页**：三个场景的入口、资源数量、最近任务。
- **联邦任务**：列表可以按名称搜索、按状态筛选。
- **新建联邦任务**：
  - AWS 控制台风格：配置面板里字段名在上、两栏对齐，控件下方不放说明；
  - 选项按钮、带单选 / 复选的表格；右侧配置摘要和预估；
  - 算法参数按注册表生成，收在"高级配置"里；
  - 窄屏时创建按钮吸底，正式运行的确认也在底部栏。
- **任务详情**：概览（本地 vs 联邦、负迁移、产出、各方变化、明细）、进度（按算法定义的步骤、各方进度、通信记录）、产出（每轮一版，可发布为应用）、配置（冻结的配置、算法参数、参与方快照）；可以暂停、继续、取消、复制为新任务。
- **应用**：任务产出发布后的成果；试用（不带 / 带应用对比，回答为示意）、内容、接入（导出 JSON；API、命令行规划中）。
- **基础管理**：
  - 参与方与数据：列表和详情、新增参与方（平台托管或参与方本地）、上传数据集并在浏览器里检查格式；
  - 算法：注册表里的算法和待接入的场景；
  - 模型接口：预留一个"默认 LLM 接口"，接口列成表格，新增和编辑共用一个表单，不保存密钥。

## 风险

- **效果**：用 gpt-5.4-mini 跑三个种子没有复现论文的提升（三轮平均 0.4578 → 0.4422 → 0.4472）；论文结果来自 DeepSeek 和 Gemini。配置模型时要考虑这一点，真实演示前先试跑确认。
- **成本**：完整复现一次约 2,700 次参与方调用，token 估计在千万量级；默认先试跑。
- **trace 隐私**：trace 可能带出题目细节；真实跨机构部署时，上传前要在参与方本地审查。
