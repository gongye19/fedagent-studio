## 一句话状态

前端已经能演示完整的使用方式：机构在工作台新建项目，按 7 个维度像下单一样选好配置（选完场景即有推荐值），创建后邀请合作机构或加入本机构的其他节点组队，各方确认后跑通准入、创建环境、执行、评测和交付；受邀方可以查看方案后接受。节点连接、Agent、运行环境、runner、评测和交付的后端尚未接入。

## 已完成

### 维度与方法

- 7 个维度 22 个子项：协作场景、参与方与算力、数据、模型、算法与训练、安全与隐私、评测与交付，定义见 [DIMENSIONS.md](./DIMENSIONS.md)。
- 4 个场景：横向联邦训练（Flower）、纵向联邦训练（隐语 SecretFlow）、联邦统计分析、Agent 记忆联邦。
- 12 个模型：ResNet-18、MLP、XGBoost、逻辑回归、Qwen2.5-1.5B-Instruct、Qwen3-1.7B、Llama-3.2-3B-Instruct、SecureBoost、SS-LR、两种统计分析、Agent 记忆条目。
- 算力约束：5 档规格按 vCPU、内存、显存描述，约束数据类型、模型和 LoRA / QLoRA。
- 安全与隐私按作用位置拆开：基础安全（锁定）、SecAgg+、差分隐私、同态加密或秘密分享、输出保护。

### 使用方式与界面

- 工作台：我的项目、收到的邀请、我的节点、我的数据；可重置演示数据。
- 新建项目：7 个维度全部展开，锁定项显示固定值，冲突项置灰；右侧订单摘要（配置清单、平台推导、资源与耗时预估、注意事项）；手机端底部订单栏。
- 项目详情：七步时间轴（配置 → 参与方 → 准入检查 → 创建环境 → 执行 → 评测 → 交付），自动停在当前进度。
- 组队：本机构绑定节点或交付新节点；邀请合作机构（五步状态，可模拟对方处理）；示例机构一键补齐；组织内部添加其他节点；文件类场景上传文件由 Agent 检查。
- 邀请：查看完整方案和对本机构的要求，选择满足规格的节点和数据后接受，或拒绝；接受后由模拟的发起方启动和交付。
- 交付：按配置的交付范围，指定参与方时勾选；按机构去重。
- 演示数据保存在浏览器本地，刷新后自动续上。
- 界面统一中文、字号不小于 11px、状态色对比度 ≥ 4.5:1、触屏点击目标 ≥ 44px。

## 技术债务与风险

- 各选项的适用条件和算力要求目前写在前端注册表里，后端阶段应改为由 runner manifest 声明，前端只展示。
- 资源与耗时预估是粗略量级，接入真实 runner 后应按实测校准。
- 参与方、指标和产物都是演示数据，界面和文档必须持续标明"模拟"。
- 保护配置容易被误解为已实现安全能力。
- Agent 记忆联邦还没有公认的标准算法，合并、冲突处理和验证规则需要在 demo 里逐步定下来。
- 纵向依赖隐语，需要验证 SecureBoost / SS-LR 与平台节点程序的集成方式（隐语通过 Kuscia 调度）。
- 截图目录包含多轮历史设计，正式汇报使用 README 中引用的截图。
