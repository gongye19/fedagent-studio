# 当前进展

更新时间：2026-09-29
版本：0.4.0 前端原型（联邦 Agent）

## 一句话状态

项目已改为只做联邦 Agent。前端原型可以完整演示使用方式：

- 先登记参与方和数据集（数据集登记时选定场景和任务类型）；
- 新建联邦任务：依次选场景、任务类型、算法，再勾选参与方，每方出一份匹配的数据集；
- 看每轮进度和"本地 vs 联邦"的结果；
- 把产出发布为应用，并试用或导出。

任务运行和结果都是示例数据；后端、FoT 引擎、模型网关和参与方本地客户端尚未实现。

## 已完成（前端）

### 场景、算法与数据

- 3 个场景：
  - 横向联邦 Agent：可用，算法是 FoT；
  - 纵向联邦 Agent、联邦迁移 Agent：规划中，只说明用途和所需数据。
- 算法注册表：FoT 声明了适用的任务类型、交换内容（解题经验）、产出（经验库）、4 个可调参数、每轮 6 步和每一步的预估用量；平台的预估、进度和任务推进都只按注册表计算。
- 内置 8 个平台托管的示例参与方（参与方 A–H），各持一份数学推理数据集（AIME24、AIME25、AMC、CCEE、CNMO、WLPMC、V202412Hard、V202505Hard，共 300 条样本），都登记在"横向联邦 · 数学推理"下。另有一个等待连接的本地参与方示例。
- 概念分开：场景（各方的数据怎么分布）、任务类型（Agent 做什么）、算法（各方怎么协作）来自注册表；参与方（机构或节点，不绑定场景）和数据集（属于一个参与方，登记时选定场景和任务类型）由用户登记；联邦任务把它们组合起来，每个参与方出一份数据集。

### 页面

平台按通用情况设计：场景、任务类型、算法、算法参数、每轮步骤、交换内容、产出和预估用量都来自注册表，FoT 只是目前登记的算法。平台名称是 FedAgent Studio。导航和原 TrustFLAIR 平台一致：首页、联邦任务、应用、基础管理。

- **导航**：首页、联邦任务、应用、基础管理四个一级导航，同一个样式；基础管理点开后才出现参与方与数据、算法、模型接口。窄于 900px 时收进顶栏的"菜单"。
- **首页**：居中的"选择联邦场景"，三张卡片各带一张示意图（横向按样本分、纵向按字段分、迁移从已有领域到新领域）；可用的场景点进去就是这个场景的联邦任务配置，规划中的灰显。
- **联邦任务**：标题下一句话说明联邦任务是什么；列表可以按名称搜索、按状态筛选。
- **新建联邦任务**：
  - 依次选场景 → 任务类型 → 算法 → 参与方，每一步都由用户选，不预先填好；从首页点场景进来时场景已选好，页面只列这个场景的选项；
  - 任务类型和算法的选项最后都留一个"待接入"的空位，表示之后还会有别的；
  - 参与方表格一行一个参与方，只列出登记了同一场景、同一任务类型数据集的参与方，每方出一份（名下有几份时在行里选），表头可以全选；
  - AWS 控制台风格：配置面板里字段名在上、两栏对齐，控件下方不放说明，需要解释的字段点"说明"展开；
  - 只有一个模型时直接写出来；右侧配置摘要和预估；
  - 算法参数按注册表生成，收在"高级配置"里；
  - 中途可以去新增参与方、数据集或配置接口，保存后回到这里；新数据集和任务匹配时直接选入；
  - 窄屏时创建按钮吸底，正式运行的确认也在底部栏；有"取消"，动过的配置要确认才放弃。
- **任务详情**：概览（本地 vs 联邦、负迁移、产出、各方变化、明细）、进度（按算法定义的步骤、各方进度、通信记录）、产出（每轮一版，发布时填应用名称）、配置（冻结的配置、算法参数、参与方快照）；可以暂停、继续、取消（原地确认）、复制为新任务。
- **应用**：任务产出发布后的成果；试用（不带 / 带应用对比，回答为示意）、内容、接入（导出 JSON；API、命令行规划中）；可以重命名、撤下。
- **基础管理**：
  - 参与方与数据：一个页面，按场景分标签（横向 / 纵向 / 迁移），每个标签一张表，一行是参与方登记的一份数据集，任务类型是其中一列；点开一行看数据集详情、连接命令、新增数据集、删除；每个参与方至少留一份数据集；
  - 新增参与方、新增数据集都是独立页面：运行位置、场景、任务类型都由用户选，然后上传文件（平台托管，在浏览器里检查格式）或登记名称（参与方本地）；
  - 算法：按场景分组列出注册表里的算法（每行可展开看每轮步骤、参数默认值和来源），每个场景最后留一行"待接入"；
  - 模型接口：预留一个"默认 LLM 接口"，接口列成表格；新增、编辑是独立页面，接口地址和模型必填，登记的接口可以删除；不保存密钥。

### 工程质量

- React 19 + TypeScript 6 + Vite 8；ECharts 按需加载（首屏包约 350 kB，图表包单独加载）。
- 领域层与组件分离：
  - 场景与算法注册表、配置校验与预估、任务状态机、示例数据生成、数据集检查都在 `domain/`；
  - 任务配置不含任何算法专属的字段：算法参数按注册表的键保存，任务推进按步骤声明的结果类型记录结果；

## 风险

- **效果**：用 gpt-5.4-mini 跑三个种子没有复现论文的提升（三轮平均 0.4578 → 0.4422 → 0.4472）；论文结果来自 DeepSeek 和 Gemini。配置模型时要考虑这一点，真实演示前先试跑确认。
- **成本**：完整复现一次约 2,700 次参与方调用，token 估计在千万量级；默认先试跑。
- **trace 隐私**：trace 可能带出题目细节；真实跨机构部署时，上传前要在参与方本地审查。
