# 当前进展

更新时间：2026-09-28
版本：0.4.0 前端原型（联邦 Agent）

## 一句话状态

项目已改为只做联邦 Agent。前端原型可以完整演示使用方式：

- 先选场景，再选算法和数据，然后发起联邦任务；
- 看每轮进度和"本地 vs 联邦"的结果；
- 发布洞见库，并试用或导出。

任务运行和结果都是示例数据；后端、FoT 引擎、模型网关和参与方本地客户端尚未实现。

## 已完成（前端）

### 场景、算法与数据

- 3 个场景：
  - 横向联邦 Agent：可用，算法是 FoT；
  - 纵向联邦 Agent、联邦迁移 Agent：规划中，只说明用途和所需数据。
- FoT 的完整说明：每轮 6 步、上传什么和不上传什么、适用数据、评分方式、论文和代码来源。
- 内置 8 个数学题库（AIME24、AIME25、AMC、CCEE、CNMO、WLPMC、V202412Hard、V202505Hard，共 300 题），各由一个平台托管的示例参与方持有。另有一个等待连接的本地参与方示例。

### 页面

- **总览**：使用流程、三个场景、进行中与最近任务、资源概况、已发布的洞见库。
- **新建联邦任务**：
  - 场景 → 算法 → 数据 → 运行设置，按顺序依次出现；
  - 右侧是任务配置清单，以及调用次数、token、时长和费用的预估；
  - 手机端操作栏吸底。
- **任务详情**：
  - 进度：每轮 6 步，参与方步骤按参与方显示；可以暂停、继续、取消；
  - 结果：各项指标、每轮准确率曲线、"本地 vs 联邦"对比表；
  - 洞见库：各轮版本、新增项、关系分析，可发布；
  - 上传记录：服务端收到的 trace；
  - 配置：冻结的配置、参与方快照、审计项；
  - 可以复制为新任务。
- **洞见库**：已发布的版本；按类别浏览洞见；试用（带库 / 不带库并排对比，回答为示意）；接入方式（导出 JSON、API、命令行）。
- **参与方与数据**：
  - 两种运行位置的说明；参与方列表和详情（题库、样例题、本地客户端的连接步骤）；
  - 新增参与方；上传题库并在浏览器里检查格式。
- **模型接口**：预留一个"默认 LLM 接口"（OpenAI 兼容，服务和模型待配置），任务默认都用它；可以另外登记接口；并发上限和单价可以编辑；不保存密钥。

## 风险

- **效果**：用 gpt-5.4-mini 跑三个种子没有复现论文的提升（三轮平均 0.4578 → 0.4422 → 0.4472）；论文结果来自 DeepSeek 和 Gemini。配置模型时要考虑这一点，真实演示前先试跑确认。
- **成本**：完整复现一次约 2,700 次参与方调用，token 估计在千万量级；默认先试跑。
- **trace 隐私**：trace 可能带出题目细节；真实跨机构部署时，上传前要在参与方本地审查。
