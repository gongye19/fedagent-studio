# 项目目标

最后复核：2026-10-05（T57：真实模型全流程验证通过；整理交接）

## G：产品目标

FedAgent Studio 是通用的联邦 Agent 平台：让多个参与方的 Agent 在不交出原始数据和标注的前提下一起变强。

各方之间只交换算法声明的内容，由服务端汇总后下发；交换什么、谁能读到，写在算法清单里，由平台执行。第一个算法 FoT 交换的是文本形式的解题经验（trace），服务端把它们汇成经验库。

用户先选场景，再选任务类型、算法和数据。平台负责：

1. 按场景、任务类型组织算法和数据。
2. 运行联邦任务：按算法声明的步骤在各方和服务端之间逐轮推进，支持暂停、继续和断点续跑。
3. 如实展示结果：本地基线与联邦之后的对比、负迁移、各轮产出和服务端实际收到的内容。
4. 让产出能被使用：发布为应用、试用、导出和 API 调用。
5. 支持两种参与方运行位置：平台托管用于演示和算法验证，参与方本地用于真实的跨机构联邦。
6. 方便扩展：算法、任务类型、判分方式、参与方的运行方式、数据格式和模型服务都以插件接入，不改核心。

平台不自己发明联邦算法：第一个算法是已发表的 FoT（Federation over Text，arXiv:2604.16778），引擎基于已审计的复现器。Agent 相关的方法可以有创新，其他部分用主流、成熟的做法。

## 第一版范围

- **场景**：横向联邦 Agent 可用，算法是 FoT；纵向和迁移显示为规划中，算法待定。
- **数据**：内置 8 个数学题库（来自 FoT 复现包，共 300 题）：AIME24、AIME25 随代码一起，另外 6 份从 FoT 代码包导入；也可以上传同格式的题库。
- **参与方**：第一版以平台托管为主；参与方本地的客户端（fedagent-client）已经能领取、执行和提交，安装包由平台提供（部署时构建）。
- **模型**：任意 OpenAI 兼容的接口，由用户在界面上配置，每个接口从接口提供的模型里选一个；现在接的是 David AI 的 gpt-5.6-luna。测试用的假模型只在本地开发和自动测试里有。
- **当前阶段**：前端和后端第一版都已完成，部署在实验室服务器（只在 Tailscale 内网访问）；下一步配置真实模型试跑。

## 当前不承诺的能力

- **FoT 的实际效果**：已知用 gpt-5.4-mini 跑三个种子没有复现论文的提升；论文结果来自 DeepSeek 和 Gemini。用假模型跑出的准确率和经验库只用来验证流程。
- **真实模型**：David AI 的 gpt-5.6-luna 已跑通完整流程；小试跑验证运行链路，不能据此证明 FoT 的效果。
- **命令行**：现在只有运维命令，按配置文件创建任务等命令以后加。
- **本地客户端**：能用，安装包由平台提供，上传前可以逐条确认（`--review`）；还没有发布到公共仓库，也没有过滤规则。
- **纵向和迁移**：没有算法。
- **预估**：调用次数是精确的；token、时长和费用是按口径估算的量级。
