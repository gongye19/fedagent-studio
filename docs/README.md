# 文档索引

建议按以下顺序阅读：

1. [项目目标](./GOAL.md)：平台要解决什么、第一版范围、验收标准和当前不承诺什么。
2. [使用流程](./FLOW.md)：谁在用，怎么发起任务、看结果、用经验库，参与方怎么加入。
3. [系统架构](./ARCHITECTURE.md)：后端设计。插件体系与扩展点、三种场景、任务编排、执行器（参与方的运行位置）、数据、评测、产出与应用、模型网关、API、存储、安全、开发测试与部署、FoT 插件。
4. [当前进展](./PROGRESS.md)：已经完成和还没做的能力、服务器情况，以及风险。
5. [开发说明](./DEVELOPMENT.md)：本地启动、代码结构、如何增加算法和接入后端。
6. [关键设计决策](./DECISIONS.md)：背后的取舍，以及哪些决定已被废弃。
7. [任务记录](./HISTORY.md)：按时间顺序的 T 任务。
