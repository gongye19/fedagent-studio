# 运行流程

最后复核：2026-09-28（T27）

## 使用方式

平台按"项目"组织联邦协作，支持两种组队方式：

- **发起 + 邀请（跨机构）**：一方创建项目、选好配置，邀请合作机构；对方接受、绑定节点、授权数据并确认方案后开始。
- **组织内部联邦**：同一机构把自己的多个节点（不同分支、机房）各作为一方加入同一个项目；文件类场景则上传多份文件，每份检查通过的文件算一方。

配置只由发起方决定，其他方只能确认或拒绝；确认之后发起方不能再改配置，要改就新建项目。平台默认不展示其他机构的任何内容，只有同一项目的参与方能看到彼此授权的描述信息（节点规格、数据摘要），看不到原始数据。

演示环境预置了示例机构（界面标"示例"），它们会自动完成加入流程，方便单独一个人体验完整流程。

## 页面

```text
工作台 ──► 新建项目（7 个维度 + 订单摘要）──► 项目详情（七步时间轴）
   │                                            ▲
   └──► 收到的邀请 ──► 选择节点和数据，接受并确认方案 ┘（本机构为参与方）
```

- **工作台**：我的项目（名称、角色、参与方进度、状态）、收到的邀请、我的节点（规格、在线状态）、我的数据（只登记描述）。
- **新建项目**：按 [DIMENSIONS.md](./DIMENSIONS.md) 的 7 个维度选择，右侧订单摘要实时显示配置清单、平台推导和资源与耗时预估；确认后创建项目。手机端底部固定显示订单操作栏。
- **项目详情**：左侧为当前步骤，右侧为七步时间轴和项目概况；未手动切换时自动停在当前进度。
- **邀请详情**：发起方的完整配置、对本机构的要求（角色、节点规格、数据类型、网络、交付范围）、已在项目中的机构；选择节点和数据后接受，或拒绝。

## 七步时间轴

### 1 配置（已锁定）

显示创建时冻结的 7 个维度取值和平台推导。修改配置需要新建项目。

### 2 参与方

- **参与要求**：最少参与方数量、节点规格、数据类型、网络、本机构角色（纵向）和数据要求。
- **本机构节点**（节点类场景）：从本机构在线且满足规格的节点中选择，或按配置交付新节点（公有云创建实例 / 私有机房安装包）；再选择授权给本项目的数据。节点交付完成后自动确认。
- **邀请合作机构**：输入机构名称或邮箱；受邀机构依次经过 已邀请 → 已接受 → 节点就绪 / 文件已提交 → 数据已授权 / 检查通过 → 已确认方案。演示环境不会真的发出邀请，可点"模拟对方处理"推进，或直接添加示例机构、一键补齐。
- **添加本机构其他节点**（组织内部联邦）：把另一个节点作为一方加入。
- **上传本机构文件**（文件类场景）：由 Agent 检查格式、字段和条数，不符合时逐项说明原因和建议。
- **开始条件**：已确认的参与方不少于最少数量，本机构节点已就绪，且没有检查中或未通过的文件。未完成的参与方不参加本次运行。发起方点"开始运行"后参与方冻结。

受邀的项目由对方发起方开始运行；本机构确认后，演示环境会模拟发起方启动。

### 3 准入检查

硬规则检查场景与框架、参与方数量、每个节点的算力规格、数据类型、样本对齐、纵向标签方（恰好 1 个）、大模型基座一致性、安全机制（SecAgg+ 至少 3 方），并列出配置中的注意事项。Agent 把结构化结果翻译成说明，不能覆盖拒绝。

- 当前：确定性的规则模拟 + Agent 说明文案。
- 后端：policy engine + 只读 Agent，输出可审计 `PreflightReport`。

### 4 创建环境

冻结运行计划，按执行模式创建协调方和各参与方的运行环境，挂载只读数据，设置默认拒绝的网络策略。

- 当前：模拟进度和日志。
- 后端：平台侧 Flower SuperLink / 隐语调度服务 / 隔离沙箱；参与方侧由节点程序拉起对应运行时。

### 5 执行

按执行模式运行：多轮联邦（下发 → 本地训练 → 回传 → 按聚合算法合并，重复所选轮次）、纵向协议（隐私求交 + 加密交换中间结果）、单轮汇总（由计数和求和算整体结果）、单轮合并（记忆脱敏、去重、冲突仲裁）。

- 当前：每个场景用自己的执行模式模拟，真实耗时显示为订单摘要中的预估。
- 后端：Flower（横向）、隐语 SecretFlow（纵向）、平台统计服务和记忆合并服务。

### 6 评测

按所选评测方式对比基线（单方模型、基座模型或各方原有记忆），按闸门规则（不低于基线、下降不超过阈值、不高于上限）判断。未通过闸门的结果不能交付。

### 7 交付

评测通过后由发起方确认交付；交付范围在配置时已选定（仅发起方 / 全部参与方 / 指定参与方，后者在这一步勾选）。交付后可查看交付物、交付对象、谱系和冻结的运行计划。受邀项目由对方发起方确认交付；交付范围为"仅发起方"时本机构不会收到交付物。

- 当前：模拟交付，不生成真实文件。
- 后端：产物登记、访问控制、审计记录和生命周期策略。

## 状态约束

- 未选场景不能创建项目；创建后配置冻结。
- 参与方不足、本机构节点未就绪、有文件检查中或未通过时不能开始运行。
- 准入未通过，不能创建环境，后续阶段都不会运行。
- 运行开始后参与方冻结。
- runner 失败只能重试当前阶段或从快照恢复，不能伪造后续成功状态。
- 评测未通过，不能交付；交付必须由发起方确认。

## 演示数据的保存

项目、节点、邀请和进度保存在浏览器本地（localStorage），刷新后自动续上计时；工作台的"重置演示数据"恢复初始状态。
